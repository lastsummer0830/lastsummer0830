## 소개

**Java · Spring 기반 백엔드 개발자.**

팀 프로젝트에서 주로 도메인 설계와 DB 모델링 담당. 개인 프로젝트로는 게임 엔진 없이 2D 타일 RPG 제작 중.
기능을 나열하기보다 **어떤 문제를 왜 그렇게 풀었는지** 설명 가능한 개발을 지향.
